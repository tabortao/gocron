# 用户管理页面优化计划

## 任务目标

将用户管理页面优化为简约商务风格，与定时任务页面风格保持一致，并适配移动端。

## 设计方向

- **风格**: 简约商务风格，与定时任务页面一致
- **配色**: 使用灰色调为主，搭配蓝色强调色
- **布局**: 最大宽度1200px居中，响应式设计
- **移动端**: 卡片式布局替代表格

## 任务清单

### 1. 页面结构优化

- [x] 重构页面容器结构，使用 `.page-container` 统一布局
- [x] 优化页面头部，添加用户统计信息展示
- [x] 统一按钮样式

### 2. 数据表格优化

- [x] 优化表格样式，使用现代化边框和背景
- [x] 优化状态显示，使用开关组件
- [x] 优化操作按钮布局

### 3. 移动端适配

- [x] 添加移动端卡片列表视图
- [x] 响应式布局调整
- [x] 隐藏/显示元素切换

## 技术要点

- 使用 Vue 3 Composition API 重构
- 保持现有功能逻辑不变
- 复用定时任务页面的样式变量和组件
