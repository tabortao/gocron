# 任务计划：定时任务编辑页面优化

## 任务目标

优化定时任务新增/编辑页面，采用简约商务风格，与定时任务列表页面风格一致，适配移动端，统一页面宽度。

## 任务步骤

### 1. 分析现有页面风格

- 列表页面使用了卡片式布局，最大宽度 1200px
- 简约商务风格，浅色背景，圆角卡片
- 响应式设计，适配移动端

### 2. 优化编辑页面布局

- 采用与列表页面一致的容器结构（max-width: 1200px）
- 使用卡片式布局组织表单内容
- 优化表单字段分组，提升用户体验

### 3. 实现响应式设计

- 使用 CSS Grid 和 Flexbox 实现自适应布局
- 移动端单列布局，桌面端多列布局
- 优化移动端的按钮和表单控件尺寸

### 4. 统一视觉风格

- 使用与列表页面一致的配色方案
- 统一圆角、阴影、间距等设计元素
- 优化表单标签和输入框样式

### 5. 测试优化效果

- 在桌面端和移动端验证页面效果
- 确保所有功能正常工作
