# 任务节点页面优化计划

## 任务目标

优化任务节点页面（host/list.vue），使其与定时任务页面（task/list.vue）风格一致，采用简约商务风格，适配移动端。

## 设计方向

- **风格**: 简约商务风格，与定时任务页面保持一致
- **色调**: 使用 variables.css 中定义的颜色变量，保持一致性
- **布局**: 最大宽度 1200px，居中显示，响应式设计
- **移动端**: 卡片式布局，适配手机屏幕

## 优化内容

### 1. 页面头部优化

- [ ] 采用与定时任务页面一致的 page-header 结构
- [ ] 左侧显示标题和统计信息
- [ ] 右侧显示操作按钮

### 2. 筛选区域优化

- [ ] 采用可折叠的筛选卡片设计
- [ ] 使用 filter-card、filter-header、filter-body 结构
- [ ] 筛选项使用网格布局

### 3. 内容区域优化

- [ ] 桌面端：表格布局，与定时任务页面风格一致
- [ ] 移动端：卡片式布局
- [ ] 分页组件样式统一

### 4. 响应式设计

- [ ] 768px 以下切换为移动端布局
- [ ] 隐藏桌面端元素，显示移动端卡片
- [ ] 按钮和操作区域适配移动端

### 5. 样式优化

- [ ] 使用 CSS 变量保持一致性
- [ ] 添加过渡动画效果
- [ ] 优化间距和圆角
